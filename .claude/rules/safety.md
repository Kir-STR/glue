# Safety — инварианты проекта

Операционная выжимка по safety-критичным зонам проекта: деградация без иллюзии покрытия и безопасность записи на диск. Источник правды — исходный код (`plugins/glue/src/gate.mjs`, `plugins/glue/src/session-start.mjs`, `plugins/glue/src/paths.mjs`, `plugins/glue/src/apply.mjs`); при изменении кода — обновлять и здесь; расхождение решается в пользу кода.

## Kill switch / плавная деградация

Kill switch неприменим: у Glue нет долгоживущего рантайма и внешних сервисов.

Плавная деградация — применима и реализована:

- **Гейт native↔fallback** (`plugins/glue/src/gate.mjs`) — presence-gate: обязательные Claude-файлы отсутствуют или манифест непригоден → SessionStart-хук впрыскивает fallback-инъекцию тел правил; при пустом выборе модулей — явное сообщение «контроль не применяется», не тишина.
- **Fail-transparent хук** (`plugins/glue/src/session-start.mjs`): ошибка fallback-инъекции не валит сессию (exit 0) и явно сообщает, что правила не применены, — доступность сессии сохраняется, иллюзия покрытия не создаётся; это не fail-closed enforcement: сессия продолжается без правил.
- **Битый / чужой манифест** (`plugins/glue/src/manifest.mjs`) — не crash: нечитаемый JSON → null, чужой `producerPack` / неподдерживаемая схема отсекаются; деградация до fallback и повторной доставки.

## Безопасность записи на диск

- **Разрешённые зоны** (`plugins/glue/src/paths.mjs`): каталоги `.claude/`, `.glue/` и ровно три корневых файла `CLAUDE.md` / `AGENTS.md` / `GEMINI.md`; выход за зону и абсолютные пути отвергаются до любой мутации.
- **Symlink-target запрещён** (`plugins/glue/src/apply.mjs`): lstat-проверка перед мутацией; симлинк на месте таргета → abort.
- **TOCTOU-перепроверка:** batch-preflight по `expectedCurrentHash` плюс повторная сверка перед каждой мутацией; расхождение диска с тем, что видел планировщик, → abort, не молчаливая перезапись.
- **Атомарная запись:** tmp + rename; обрыв посреди записи не оставляет усечённый файл.
- **Новый манифест публикуется последним:** при сбое посреди применения он не публикуется; предыдущий манифест может сохраниться. Восстановление — свежий обзор состояния и повторный план.
