## Принятые решения (внесение § 7 задания v16)

- **С1.** Трейсер 5.2 — первым в W4; LLM-компонент — заглушка (следствие: реальный LLM-судья подключается после R4 заменой provider-заглушки, вне среза трейсера); публичная коммуникация трейсера — только после подсреза 3.
- **С3.** Внутренние доки — RU; поставка — RU с языковым триггером: EN-перевод поставки — обязательное предусловие первой публичной коммуникации трейсера; при срабатывании совмещается с 2.5б/2.6. Двуязычие отклонено.
- **С4.** Модель публикации — continuous release: merge в main изменения `plugins/glue/**` (с обязательным бампом version) есть публикация; два независимых подтверждения перед одним физическим merge; тег — постфактум-фиксация. Триггер перехода на controlled release (исполняет 6.3): первая публичная коммуникация трейсера либо первое свидетельство внешнего использования — что раньше.
