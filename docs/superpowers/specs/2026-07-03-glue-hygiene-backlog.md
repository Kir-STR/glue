## Приоритизация → релизы

Логика порядка: сначала механизация проверок (H1 — даёт CI-гейт всем последующим PR), затем устойчивость рантайма (H2), затем ужесточение границ записи **до** adopt-среза (H3 — блокер R1), контентная гигиена — фоном (H4). Привязанное к adopt-срезу (F-09, F-13) уходит в состав R1, не сюда.

### H1 — механизация проверок (F-08, F-07)

**Цель:** запуск тестов — исполняемая команда, merge-гейт «CI зелёный» существует физически.

- `package.json` в корне репо: `private: true`, `scripts.test` с точной glob-формой (`node --test "plugins/glue/test/*.test.mjs"`), поле `engines` (минимальную поддерживаемую версию Node сверить при реализации, не по памяти; локально — v24.16.0). Без зависимостей. В `plugins/glue/` package.json не кладём — плагину для работы он не нужен, а лишний файл уехал бы в поставку.
- `.github/workflows/tests.yml`: push в `main` + pull_request; матрица ОС ubuntu + windows (path-логика на `sep`, glob-quirk Node 24/Windows — кроссплатформенное покрытие содержательно); версии Node — по решению оператора (предложение: 22 + 24).

**Acceptance:** `npm test` зелёный локально; workflow зелёный на обеих ОС; PR показывает check.

**Дисциплина:** кода не касается — по `worktree-workflow § Мелкие правки` допустим direct-to-main; ветка+PR — вариант «сразу dogfood гейта». Решение оператора: ветка+PR.

**Статус: done (2026-07-03).** PR 17 смержен rebase'ом → `main acaa6f5`; PR-прогон и push-прогон на `main` — оба 4/4 pass. **Гипотеза `engines: >=22` подтверждена** — Node 22 зелёный на обеих ОС, правка не требуется. Simplify-триаж: 1 finding (дубль Node-версии engines↔matrix) отвергнут — разные единицы знания (заявленный минимум vs доказательная выборка). Follow-up: `actions/checkout@v4`/`setup-node@v4` дают deprecation-warning (таргетят Node 20 runtime) — бамп до v5 мелкой правкой при случае.

### H2 — устойчивость CLI/status (F-01, F-02, F-06)

**Цель:** контракт «CLI всегда отвечает JSON» и «status не бросает» держится под битыми входами.

- Единообразная обёртка ошибок для всех подкоманд `bin/glue.mjs` (JSON `{ok:false, error}` + stderr + exit 1 — как уже сделано у `init`).
- `manifest.mjs:26`: `f?.producerPack`.
- `status.mjs`: движок без entry в `files[]` → `errors`, не `drift`.
- Тесты: битый bundle → `list`/`status` отвечают JSON; манифест с `files: [null]` → status деградирует, не бросает; несогласованный `engines`/`files` → `errors`.

**Дисциплина:** код → worktree + PR.

**Статус: done (2026-07-03).** PR 18 смержен rebase'ом → `main e375f4f` (fix `109addb` + simplify `e375f4f`). TDD: 5 новых тестов RED→GREEN, итог 93/93; CI 4/4 на PR и на `main`. Simplify: 6 findings, применены 2 (emitUnknown→emitError; const planned), отвергнуты 4 (outputJson, кеш diskHash, снятие Array.isArray-защит) — обоснование в теле simplify-коммита.
