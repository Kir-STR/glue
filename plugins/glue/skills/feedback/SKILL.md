Отзыв о Glue — GitHub issue в `Kir-STR/glue`. Одна проблема — одна issue.

1. **Составь текст.** Заголовок — суть проблемы одной строкой. Тело:
   - **Версия и среда:** версия Glue (из `.glue/manifest.json` или `plugin.json`), ОС, значимые настройки;
   - **Что произошло;**
   - **Ожидание;**
   - **Воспроизведение** — минимальные шаги;
   - **Обход** и **Предложение** — если есть.

   Issue публичные: не включай приватные пути, имена и идентификаторы проекта пользователя, код и секреты. Стандартные пути Glue (`.glue/manifest.json`, `.claude/rules/*.md`) допустимы.

2. **Покажи оператору** полный текст и репозиторий назначения. Публикуй только после явного «да».

3. **Опубликуй:** запиши тело во временный файл и выполни `gh issue create -R Kir-STR/glue -t "<заголовок>" -F <файл>`; покажи ссылку. Если `gh` недоступен или не авторизован — отдай оператору готовый текст и ссылку https://github.com/Kir-STR/glue/issues/new для ручного создания.
